# mirang-progress

Claude Code 옆에 **작업 진행도 패널**을, 입력창 위에 **현재 작업 줄과 픽셀 게 캐릭터**를 보여 주는 한국어 모드입니다. 진행을 보여 주기만 하고, 작업을 나누거나 프롬프트·모델을 바꾸지 않습니다.

## 보여 주는 것

- **현재 작업 줄**: 작업 제목, 보고된 단계(done/total), 진행 막대, 캐릭터
- **작업 진행도 패널**: 메인 작업과 하위 작업자(subagent)마다 모델, 맥락 사용률, 토큰, 예상 비용, 걸린 시간
- **예상 비용·토큰**: 메인 세션과 하위 작업자의 모델 요청을 모델별 정가로 계산한 추정치. **청구액이 아닙니다.** 구독 요금제라면 추가 결제가 아니라 사용량의 크기를 가늠하는 값입니다.
  - 캐시 쓰기는 1시간 요율로 계산하므로 실제와 차이가 날 수 있습니다.
  - 단가를 모르는 모델(다른 제공자, 새 모델)은 추측하지 않습니다. 금액 뒤에 `+`를 붙이거나 "단가 미상"으로 표시합니다.
  - 집계 범위는 **현재 작업(flow) 하나**입니다. 질문에 답하며 여러 턴에 걸쳐도 같은 작업이면 합산하고, 새 작업 제목이 보고되거나 작업이 끝나면 새로 셉니다. 그때 아직 돌던 이전 작업의 백그라운드 작업자는 "이전 작업"으로 표시만 하고 새 작업 합계에는 넣지 않습니다. 시간은 응답을 기다린 시간을 빼고 일한 시간만 셉니다.
- **메인 맥락**: 세션이 알려 주는 실제 맥락 크기를 씁니다(하위 작업자는 모델명으로 추정).
- 데스크톱 앱은 움직이는 SVG, 터미널은 텍스트 막대로 그립니다. 모션 줄이기 설정을 따릅니다.

## 쓰는 법

- 세션이 시작되면 패널이 자동으로 열립니다. `/work-progress`로 열고 닫고, `/work-progress open`으로 다시 엽니다. 직접 닫은 패널은 다음 턴에 다시 열리지 않습니다.
- Claude가 여러 단계 작업을 할 때 `mcp__mirang-progress__progress` 도구로 제목과 단계를 보고하면 막대가 채워집니다. 함께 들어 있는 `report-progress` 스킬이 보고 방법을 알려 줍니다.
- 하위 작업자는 `mcp__mirang-progress__step`으로 자기 단계만 보고합니다.
- 단계가 보고되지 않으면 퍼센트를 지어내지 않고 "단계 미보고"와 —를 표시합니다.

### 상태 표시

응답이 끝났다고 작업이 끝난 것으로 보지 않습니다.

| 표시 | 뜻 |
|---|---|
| 작업 3/8 (보라) | 진행 중 |
| 답변 대기 3/8 (주황) | 보고된 단계가 남은 채로 응답이 끝남. Claude가 질문하고 기다리는 경우 등. 다음 메시지에서 진행도를 이어 감 |
| 완료 보고 전 8/8 (주황) | 단계는 모두 찼지만 `finished: true` 보고가 없음. 완료로 보지 않음 |
| 중단 3/8 · 오류 3/8 (빨강) | 사용자가 멈췄거나 API 오류로 끝남. 다음 메시지에서 이어 감 |
| 작업 완료 (초록) | `finished: true`로 보고함. 이것만 완료 기준 |
| 응답 완료 (초록) | 단계 보고 없이 답만 한 턴 |

### 진행 막대가 채워지게 하려면

Claude가 진행도를 보고해야 막대가 채워집니다. 보고가 없으면 캐릭터·토큰·비용·시간만 움직이고 막대에는 "단계 미보고"가 나옵니다. 매번 보고하게 하려면 `~/.claude/CLAUDE.md`(모든 프로젝트) 또는 프로젝트의 `CLAUDE.md`에 아래 한 줄을 넣으세요.

```
- 여러 단계 작업은 시작할 때와 단계를 마칠 때마다 mirang-progress 진행도 도구(mcp__mirang-progress__progress)로 제목·전체 단계·완료 단계를 보고한다.
```

## 출처와 라이선스

[johnnyvizz](https://github.com/johnnyvizz)의 [savvy-progress](https://github.com/johnnyvizz/claude-kit/tree/main/plugins/savvy-progress)(MIT 라이선스)에서 진행 막대·픽셀 캐릭터·작업자 패널을 가져와 한국어 표시 전용으로 고친 것입니다.

- 픽셀 게 캐릭터와 의상은 savvy-progress의 그림을 그대로 씁니다. 원작 코드에는 DockCrab(Clawdy)의 스프라이트를 바탕으로 했다고 적혀 있습니다.
- 여기에 더한 것: 한국어 화면, 작업자 없이 하는 직접 작업에도 캐릭터 표시, 메인 세션의 토큰·예상 비용 집계, 하위 작업자의 자기 단계 보고(`step`), 중단·답변 대기를 완료로 표시하지 않고 다음 턴에 이어 가기, 작업 단위 비용 집계.

라이선스는 [MIT](LICENSE)이며, 원작자의 저작권 표기를 함께 둡니다.
